# Complete screenshot gallery / Vollständige Screenshot-Galerie

All 48 screenshots use fictional family events and were captured from an earlier project version. They illustrate view and design options; individual labels and details may differ from the current card. In images 32 and 36, the old browser-only assignment explanation is obsolete: shared assignments now require the optional companion integration. Screenshot configurations are examples, not instructions to change your calendars.

Alle 48 Screenshots verwenden fiktive Familientermine und stammen aus einem früheren Projektstand. Sie zeigen Ansichts- und Gestaltungsmöglichkeiten; einzelne Beschriftungen und Details können von der aktuellen Karte abweichen. In Bildern 32 und 36 ist der alte Hinweis zur rein lokalen Zuordnung überholt: gemeinsame Zuordnungen benötigen jetzt die optionale Begleitintegration. Die Bildkonfigurationen sind Beispiele und keine Aufforderung, deine Kalender zu verändern.

Download this folder to open [the interactive gallery](index.html) locally. GitHub displays the previews below directly. Each numbered configuration contains example calendar entities that must be adapted to your installation.

Diesen Ordner herunterladen, um [die interaktive Galerie](index.html) lokal zu öffnen. GitHub zeigt die Vorschaubilder unten direkt an. Die nummerierten Konfigurationen enthalten Beispiel-Kalenderentitäten, die an deine Installation angepasst werden müssen.
